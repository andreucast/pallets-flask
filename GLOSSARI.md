# Glossari tècnic

### Backlog
- Anglès: backlog
- Definició: llista de tasques pendents d'un projecte, ordenades segons la seva prioritat.
- Exemple: vam afegir les tasques pendents del blog al backlog.

### Board
- Anglès: board
- Definició: vista visual que mostra les tasques organitzades en columnes segons el seu estat.
- Exemple: vam utilitzar el Board per veure quines tasques estaven acabades.

### Branch
- Anglès: branch
- Definició: branca de Git que permet treballar en canvis separats sense modificar directament una altra branca.
- Exemple: vam crear una branch per desenvolupar una funcionalitat.

### Commit
- Anglès: commit
- Definició: registre d'un conjunt de canvis guardats al repositori Git.
- Exemple: vam fer un commit després de modificar un fitxer.

### Fork
- Anglès: fork
- Definició: còpia d'un repositori que es crea al nostre compte de GitHub per poder-hi treballar.
- Exemple: vam fer un fork de pallets/flask.

### Git
- Anglès: Git
- Definició: sistema de control de versions que permet registrar i consultar els canvis dels fitxers.
- Exemple: vam utilitzar Git per controlar els canvis del projecte.

### GitHub
- Anglès: GitHub
- Definició: plataforma en línia que permet allotjar repositoris Git i col·laborar en projectes.
- Exemple: vam pujar el nostre repositori a GitHub.

### Issue
- Anglès: issue
- Definició: element que descriu una tasca, un problema o una millora que cal gestionar.
- Exemple: vam crear un Issue per revisar les rutes del blog.

### Kanban
- Anglès: Kanban
- Definició: mètode visual per organitzar el treball i seguir l'estat de les tasques.
- Exemple: vam utilitzar un taulell Kanban per veure el progrés.

### Merge
- Anglès: merge
- Definició: operació que integra els canvis d'una branca en una altra.
- Exemple: vam fer un merge per integrar els canvis revisats.

### Pull request
- Anglès: pull request
- Definició: proposta per revisar i integrar uns canvis en una altra branca d'un repositori.
- Exemple: vam obrir una pull request per demanar una revisió.

### Repositori
- Anglès: repository
- Definició: espai on es guarden els fitxers d'un projecte i el seu historial de versions.
- Exemple: el repositori pallets-flask conté els fitxers del projecte.

### Scrum
- Anglès: Scrum
- Definició: marc de treball àgil que organitza el desenvolupament en períodes curts i amb objectius concrets.
- Exemple: vam organitzar la feina en dos sprints.

### Sprint
- Anglès: sprint
- Definició: període de temps limitat en què l'equip treballa per completar un conjunt de tasques.
- Exemple: vam repartir els Issues entre dos sprints.

### Sprint Backlog
- Anglès: sprint backlog
- Definició: conjunt de tasques seleccionades per treballar durant un sprint.
- Exemple: vam moure les tasques de l'Sprint 1 a Sprint Backlog.

### Status
- Anglès: status
- Definició: camp que indica en quina fase del flux de treball es troba una tasca.
- Exemple: vam canviar l'status d'una tasca a In Progress.

### Tauler Kanban
- Anglès: Kanban board
- Definició: taulell amb columnes que representen les fases per les quals passen les tasques.
- Exemple: vam crear columnes Backlog, In Progress i Done.

### Vista Table
- Anglès: table view
- Definició: vista que presenta els elements del projecte en files i columnes per facilitar-ne la consulta i planificació.
- Exemple: vam agrupar la Table per Iteration.
